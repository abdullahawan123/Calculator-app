# Calculator App

A simple and functional calculator application built using **Flutter** and **Dart**. This project demonstrates basic arithmetic operations, clean UI design, and Flutter widget structuring for interactive mobile applications.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Responsive and user-friendly design
- Clean interface with button inputs
- Built with Flutter for cross-platform support

## Tech Stack

- Flutter
- Dart

## Getting Started
